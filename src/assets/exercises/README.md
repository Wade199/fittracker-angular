## 🎨 Formats acceptés

- `.jpg` (recommandé)
- `.png`
- `.webp`
- `.svg`

**Note :** Le code cherche d'abord `.jpg`. Si tu utilises un autre format, renomme l'extension dans le code ou convertis tes images en JPG.

---

## 🔄 Comportement

1. **Si l'image existe** → elle s'affiche
2. **Si l'image est introuvable** → un SVG stylisé est généré automatiquement selon la catégorie (PUSH/PULL/LEGS/CORE)

Pas besoin de redémarrer l'application — ajoute simplement tes images et rafraîchis la page.

---

## 📐 Dimensions recommandées

- **Cartes exercices** : 400×300px minimum
- **Page détail** : 800×600px minimum
- **Format** : 4:3 ou 16:9
- **Poids** : < 200 Ko par image (optimise avec TinyPNG ou Squoosh)
